More intention.

Meaningful challenge and incidental toil are not the same thing. Joy lets you keep the design, discovery, or craft you want—and hand off the rest without guilt.

Ask when it helps

For substantial, ambiguous work, Joy asks what should remain yours. Clear or trivial tasks keep moving.

No moral hierarchy

  claim = self._repository.claim_due(now=now, lease_seconds=self._policy.lease_seconds)
+ self._transport.send(
+     claim.endpoint,
+     claim.payload,
+     idempotency_key=claim.idempotency_key,
+ )
+ if crash_after_send:
+     raise CrashAfterSend("delivery succeeded before its local acknowledgement")
+ if not self._repository.mark_delivered(claim, now=now):
+     raise LostLease(claim.delivery_id)

Why it matters: the remote effect and local acknowledgement cannot be atomic. The chosen contract permits redelivery with the same idempotency key rather than pretending exactly-once delivery exists.

Read the rationale ↗
Keep

At-least-once delivery

A successful remote effect may be repeated after a crash. The stable key is part of the contract.

Pair

Attempts are generations

A stale worker cannot acknowledge or reschedule work after a newer lease has been claimed.

Keep

Retry forever—for now

The example has no dead-letter policy. That omission remains an explicit product decision, not a hidden default.

Delegate

Verification plumbing

SQLite persistence, a deduplicating fake receiver, fault injection, and the test harness support the chosen semantics.
