Set the boundary

Decide who does what.

Keep the design, debugging, or implementation work you want to do yourself. Delegate setup, fixtures, or the whole task.

One question, when needed

Joy asks at most one ownership question for substantial, ambiguous work. It skips trivial tasks and work you have already delegated.

Full delegation is an option

Learning, hands-on coding, and full delegation are all supported.

Change your mind

Your latest instruction takes precedence. Move work between Keep, Pair, and Delegate whenever you need to.

The send-before-ack crash window

self._transport.send(
    claim.endpoint,
    claim.payload,
    idempotency_key=claim.idempotency_key,

if crash_after_send:
    raise CrashAfterSend("delivery succeeded before its local acknowledgement")

if not self._repository.mark_delivered(claim, now=now):
    raise LostLease(claim.delivery_id)

The remote send and local acknowledgement cannot be atomic. A crash between them can cause redelivery with the same idempotency key.

Decision log

Why redelivery is allowed

Read the rationale ↗
Keep

At-least-once delivery

A successful send may be repeated after a crash. Retries reuse the same idempotency key.

Pair

Attempts are generations

A stale worker cannot acknowledge or reschedule work after a newer lease has been claimed.

Keep

No dead-letter policy

Failed deliveries retry indefinitely. A production deployment needs an explicit policy for when to stop.

Delegate

Test support

SQLite storage, a fake receiver, and injected failures make the delivery rules testable.

Install

Install Joy.

Joy follows the Agent Skills standard and has no runtime dependencies.

Install globally with skills.sh 
npx skills add JGalego/Joy --skill joy --agent claude-code --global --yes

Invoke it

Start with the default collaborative mode.

/joy pair

Use the plugin

Add the marketplace, then install Joy from it.

/plugin marketplace add JGalego/Joy /plugin install joy@joy
